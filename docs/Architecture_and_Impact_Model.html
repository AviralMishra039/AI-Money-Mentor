1. Architecture Document

AI Money Mentor is a 5-agent orchestrated pipeline that delivers real-time, personalised financial advice to Indian salaried employees. The system combines deterministic financial calculations with LLM-generated insights, wrapped in a compliance guardrail layer to ensure SEBI-safe advisory language.

System Architecture Diagram

Agent Roles & Communication

Agent Role Type Input → Output Error Handling
① Validator Validates all user inputs per feature-specific rules (range checks, logical consistency) Deterministic Raw form inputs → valid: bool + errors[] Returns descriptive errors; pipeline halts immediately if validation fails
② Calculator Executes pure financial math: health scoring (6 dims), tax comparison (Old vs New), life‑event asset allocation Deterministic Validated inputs → Calculated financial data Cannot fail (mathematical); guarantees output even without AI
③ Router Heuristic complexity router — assigns llama-3.1-8b-instant for simple tasks, llama-3.3-70b-versatile for complex ones Heuristic Feature + inputs + calculated → Model selection + reason Always succeeds; defaults to 8B model if no rule matches
④ Insight Generator Calls Groq LLM API with structured prompts to generate actionable, personalised advice in strict JSON format AI / LLM Calculated data + model → Ranked insights, missed deductions, or action timelines Graceful fallback: if AI is unavailable or response parsing fails, system returns math-only results with a "fallback mode" notice
⑤ Guardrail Regex-based compliance filter that strips directive phrases like "you must buy" and replaces with softer advisory language Compliance Raw AI output → Sanitised output + flagged_count Passthrough if no AI output; never blocks pipeline

Orchestration Flow

1
User submits financial inputs from the UI (Health / Tax / Life Event page).
2
Validator checks inputs. On failure → pipeline halts, error returned, audit logged.
3
Calculator produces deterministic financial results (always succeeds).
4
Router determines LLM complexity tier based on income level, debt load, or event type.
5
Insight Generator calls Groq API → receives structured JSON. On failure → fallback_mode = true.
6
Guardrail sanitises AI output, replacing 7 categories of directive financial language.
7
Audit Logger persists the full step trace (agent, status, latency, I/O signature) to localStorage.
8
UI receives merged result. User can ask follow‑up questions via Context Chat (separate LLM call).

Tool Integrations

localStorage Audit trail persistence (last 50 sessions) Client-side, zero infrastructure — swap for DB in production
Key Design Decision: The Calculator agent always runs before the AI agent. This guarantees that users always receive accurate financial results, even when the LLM is unavailable. The AI layer is supplementary intelligence, not the core computation.

Assumption Base

  • Target user: Indian salaried professional, CTC ₹8–25 LPA, age 25–45
  • Avg. traditional CA tax consultation: ₹2,000 fee + 50 min travel/wait + 15 min meeting = ~65 min total
  • AI Money Mentor session: ~8 min input + ~10 min review = ~18 min total
  • Time saved per session: 65 − 18 = 47 minutes
  • Avg. missed deductions found: ₹1,28,000 across 80C, 80CCD, 80D, and HRA gaps
  • Tax saving at effective 30% rate: ₹1,28,000 × 0.30 = ₹38,400 / user / year
  • 90% of salaried Indians under-claim deductions (CBDT data, FY2023-24)
  • Indian CA market hourly rate: ₹1,500–₹3,000 → midpoint ₹2,000 for basic tax filing
